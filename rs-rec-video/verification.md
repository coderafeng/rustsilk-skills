# 硬性验收门槛与取数方式

以下全部满足才算可交付，任一不达标必须重录。**每条门槛都要留实测数字**，不接受"看起来没问题"。

## 1. 门槛表

| 指标 | 门槛 | 取数方式 |
|---|---|---|
| 静默留白段数 | **0 段**（段间空隙 > 1.2s 即为缺陷） | 段报告的 gap 字段，或 `next.startMs − (cur.startMs + cur.durMs)` |
| 语音覆盖率 | **≥ 95%**（语音总长 ÷ **流程总长**） | 时间轴统计 |
| 静音空洞 | 0 处 ≥1.2s；片尾自然收尾可豁免但须在交付说明列出区间与原因 | `ffmpeg silencedetect` |
| 音轨 | 必须存在且非静音 | `ffprobe` 音频流 + `volumedetect` |
| 视频规格 | 与开工确认值一致（编码/分辨率/帧率/像素格式/时长） | `ffprobe` |
| 逐段画面 | 每段抽 1 帧、抽中数 = 段数、每帧能找到该段旁白所指内容；含弹框字段/下拉选项枚举的段，在**该段语音结束时刻**的抽帧上弹框/下拉必须仍在屏（或因 ≤2s 起手正处于点按过渡中，见 SKILL.md「瞬态画面旁白锁屏」） | 抽帧拼联络表目视 |
| 卡片文案 | 每张卡抽 1 帧，确认中文渲染、标题与旁白口径一致 | 同上 |
| 插卡密度 | 中间卡数量 ≤ 开头总览列出的大阶段数 − 1，且卡片累计时长 ≤ 成片总时长 8%；每张卡都落在片段计划标注的阶段边界 | `out/cards` 清单与 `segment-plan.md` 对清单 + 卡片抽帧 |
| 旁白听感 | 人工抽听所有含字段枚举的段：只念重要字段、字段间有明显停顿、无连读成串 | 耳朵 |
| 数据还原 | 录后状态 = 起点核对阶段定义的干净起点，且已二次确认 | 回页面查行 + 全库残留扫描 |
| 悬空产物 | 运行时输入与临时物区分清楚，临时物归零 | 清单核对 |
| 导航真实性 | 阶段导航为菜单真实点击，脚本中 `goto` 直达数 = 0 | 脚本静态检索 + 抽帧核验菜单在画面内 |

### 容易算错的口径

- **语音覆盖率的分母是"流程总长"，不是"成片总长"**。成片 = 开头卡 + (引导卡 + 实录) × N，卡片是画面引导件、天然无声；用成片总长当分母，会把达标的片子算成不达标（实测：语音 713s ÷ 流程 728s = 97.9% 达标，而 ÷ 成片 948s = 75% 会被误判）。
- **段尾静默要看"下一句开腔前的空白"**，即 `next.startMs − (cur.startMs + cur.durMs)`，而不是"clip 尾部还剩多少静音"——后者含切片时故意留的前置量与淡出余量，会虚高。
- **数静音缺陷时不能拿插卡成片当对象**：卡片天然无声，直接在全片上数 >1.2s 静音段会得到一堆"空洞"假故障；真段间留白只在未插卡画面轴上数。
- **卡片静音豁免要按坐标定位，不能按长度粗筛**：早期 `--cards N` 只按「静音长度 ≤ 卡长+2×门槛」豁免，实测会把**片头、片尾、乃至一个真实的卡片外大空洞**一起吞成"卡片候选"（曾让 5.14s 的非卡片空洞蒙混过关）。现在用位置感知：静音段须与某张卡片在**成片时钟**上的坐标重叠才归该卡；卡片外静音走段间容差（含 TTS 尾音衰减），超容差即判缺陷。

## 2. 一键体检

```bash
node scripts/verify-film.mjs <master.mp4> <timeline.json>   # 逐段门槛：开头静默/段尾留白/段间空隙/电平/覆盖率
node scripts/verify-film.mjs <成片.mp4> <master.json> --cards 4 --cards-at <成片时钟时间轴.json>   # 位置感知豁免（推荐）
node scripts/verify-film.mjs <成片.mp4> --cards 4           # 无坐标时退回按长度粗筛（会打出 ⚠ 告警，仅供旧产物兼容）
```
位置感知豁免需要两份时间轴各司其职：覆盖率/字段映射用**流程时钟** master，卡片起止坐标用**成片时钟**时间轴的 `cards` 数组（由拼接脚本按各件时长累加落盘，形如 `cards:[{id,startMs,endMs}]`）；两者不同源故分开传，`--cards-at` 缺省时自动退回粗筛。

打印：流规格、总时长、**时间轴字段映射与取值降级清单**、静音段分类、逐段时长核对、开头漏音、段尾留白、段间空隙、>1.2s 空洞清单；有问题时退出码非 0（2 表示参数或时间轴不可用）。
`timeline.json` 的字段取值由 `scripts/timeline.mjs` 统一解析（契约：`{ segments: [{ id, startMs, durMs, actualMs }], offsetMs, trimMs, padMs }`）：
字段名换写法（`start_ms` / `beginMs` / `audioMs` / `videoMs` 等）走别名表自动识别；**必填字段解析不到直接报错并列出该段实际键名**，
可选字段回落则在输出里打 "⚠ 取值降级"，不允许静默按 0 跑（静默降级会得到 "全部通过" 的假数据）。

**两种模式不可混用（脚本会显式跳过）**：timeline 里的 `startMs` 是**流程时钟**，插卡后的成片画面轴与之不同源，
强行换算会把取样窗口落在静音卡片上，实测会报出十几个"开头静默 8.5s"的假故障。因此：

- 逐段门槛（段尾留白、段间空隙、电平）→ 对**未插卡的全链主摄**跑。
- 最终成片 → 只跑全片级门槛（规格、卡片静音豁免、覆盖率）；覆盖率只依赖 timeline 的时长与顺序，与位置无关，故两种模式都算得出。
- 静音段分类规则：片头（总览卡 + 录制器头部对齐静默）与片尾自然收尾只报不判；卡片边界静音**优先按坐标精确豁免**（静音段与某卡成片区间重叠、且外溢在尾音/前置容差内才归该卡），卡片外的段间静音按「段间容差 = 门槛 + TTS 尾音余量」判，超出才列空洞；仅当未给卡片坐标时才退回「卡长 + 2×1.2s」长度粗筛并显式告警。**这些豁免都要打印出来，交付说明里照抄区间与原因。**

## 3. 逐段抽帧目视

```bash
node scripts/contact-sheet.mjs <master.mp4> <输出目录> --timeline <timeline.json>   # 逐段取末秒帧（--at mid 取中段）
node scripts/contact-sheet.mjs <视频目录> <输出目录> --at 2.0                        # 卡片/单段 clip 批量取帧
# 可选：--grid 4x5（列x每表行数）  --cell-w 640  --prefix card-
```

- 抽**该段旁白说完那一刻**（末秒）的帧，不抽中段：末秒最能暴露"话说完了画面还没跟上"。
  视频时间 = `段起始ms + 段时长ms − 500ms + 音频偏移ms − 头部裁剪ms`；结果为负说明时间轴有问题，脚本会当作缺陷列出。
- **目录模式同样只适用于同一画面轴**；成片插卡后请对 master 抽帧，卡片单独用目录模式抽。
- **抽完必须拼成网格联络表批量看**，单张缩略图宽度 ≥ 460px 才看得清中文；逐张打开必然漏检。
- 目视必查六项：**字幕胶囊文字**、**当前登录身份**、**旁白提到的控件是否真的在画面里**、**下拉是否处于展开态**、**所点的导航项/菜单是否在画面可视区内（未被裁切到视口外）**、**含弹框字段旁白的段在段尾帧上弹框是否还在屏**（语音未完弹框已关即判不合格，偏差容限按 SKILL.md「瞬态画面旁白锁屏」的 2s 起手规则）。
- 卡片也要抽帧：卡片标题的生成规则常有正则/前缀处理，实测就靠抽帧才发现"某一步的编号被正则吃掉、只有它不带编号"这类缺陷。

## 4. 拼接与总拼的核对

- 卡片与实录拼接前双方参数须归一（帧率 / SAR / 采样率 / 像素格式），否则 concat 后音画错位。
- 逐段拼接用重编码（`concat` filter）；全片总拼用 `concat` demuxer + `-c copy`，避免上百路输入的巨型 filtergraph 与二次有损压缩。
- **总拼后必须 ffprobe 核对总时长**：各段之和与成片误差 > 2s 即说明 copy 拼接不可靠，要回退到 filter 重编码拼接。
- 拼接后抽查音画边界：在"卡片窗口内"取样应测到纯静音（约 -91dB），在"实录窗口内"取样应有语音（mean 约 -22dB）。取样窗口**必须整段落在同一类片段内**——跨边界的取样窗口会同时测到语音，看起来像"卡片漏音"的假故障。
- **只改插卡密度的重制不必重录**：先 ffprobe 核对无卡 clip 与卡片的编码参数（实测同一录制链路产出的 h264 High / yuv420p / 30fps / SAR 1:1 / aac 48kHz 完全一致），
  参数全一致时可直接 `concat` demuxer + `-c copy` 重拼（秒级完成、零额外画质损失）；任一项不一致（常见于卡片由另一工具生成、或 clip 来自不同版本的录制器）必须回到 filter 重编码拼接。
  重拼后除了总时长核对，还要在**新的卡片边界**与**原本有卡、现在没卡的位置**各抽一帧，确认没拼错段、没漏段。

## 5. 临时产物处置

先枚举、再分类、后动手：

| 类别 | 判定 | 处置 |
|---|---|---|
| 运行时输入 | 缺了流程会直接抛错或有审计价值（业务流程文档、探测结果 JSON、镜头脚本、编排脚本） | **必须保留** |
| 本轮临时物 | 调试脚本、运行日志、冒烟片、抽帧图、中间码流 | 需求方确认后删除 |
| 非本任务产物 | 上一版成片、缓存、相邻模块文件 | **只枚举不动**，需单独授权 |

- 不在版本控制下的目录，删除**不可恢复**：必须先列清单取得确认。
- 配音缓存可再生但重合成有成本，删除前说明代价。
- 文件被进程占用而删不掉时，如实报告并指出占用来源，不得强删或改用 shell 绕过安全删除。
