# 陷阱与排障速查

## 1. 浏览器自动化硬约束

| 约束 | 原因 | 做法 |
|---|---|---|
| 可能缺席的元素读取必须显式给短超时 | `innerText()` / `textContent()` 在元素不存在时按默认 30s 等待；`.catch(() => 兜底)` 只吞异常，**吞不掉这段等待** | 先取值再断言；不得把读取函数直接写在断言参数里（等待会按断言次数成倍放大，表现为画面静默或测试假死） |
| 计数类判断不能用于异步渲染的控件 | `count()` 立即返回，对条件渲染（如 `v-if`）延迟出现的按钮会误判"不存在" | 先 `waitVisible(loc, ms)` 再判定 |
| 收起下拉不要用 ESC | 弹框内的下拉按 ESC 会连带关闭整个弹框 | 点击弹框标题区触发 clickoutside；**多选下拉选完不会自动收起**，同样需要这一下 |
| 旁白还在念弹框字段，弹框已关闭 | 业务操作填完直接点确定，且旧「段内时序」规则允许销毁画面的动作先于语音执行——字段介绍与下拉选项的旁白被留在已关闭的画面上 | 按 SKILL.md「瞬态画面旁白锁屏」：拆「开框填表＋念字段」（弹框全程在屏）与「提交＋结果确认」两段；点确定/取消/关闭最早只许在语音结束前 2s 起手 |
| 空表格不渲染分页组件 | 空数据时分页条不存在，按"存在"读取即超时 | 作为"可能缺席元素"处理 |
| 树形/懒加载选项需逐层展开 | 直接按文本查找找不到子节点（默认折叠） | 先循环点击未展开的展开图标，再按文案定位节点 |
| 下拉搜索框的中文输入 | 本地过滤型可直接键入命中；远程搜索型要等回包 | 展开后先回读选项清单确认命中方式，键入后留固定渲染等待再匹配 |
| 子进程一律传绝对路径 | 相对路径在改 `cwd` 后失效，表现为"找不到输入文件" | 路径在编排层解析一次并向下传递 |
| 菜单/导航点击必须先滚入可视区 | 视口外的菜单项被裁切，观众看不到导航路径 | 点击前 `scrollIntoViewIfNeeded()`，抽帧时核验该导航项确实在画面内 |
| 阶段导航必须真实点击菜单 | `goto` 直达路由绕过导航展示，观众仍看不到路径 | 逐级展开 → 点目标项；**用 goto 直达判不合格** |
| keep-alive 页面列表会陈旧 | 复用组件时列表不重新拉取，断言拿到上一段的数据 | 进页后强制刷新或按主键定位新行，不要假设列表已更新 |

## 2. 事实探测的常见坑

- **同一表单的不同形态要分别探测**：新增 / 编辑 / 业务转换往往是同一组件的不同模式，字段足迹不同。按别的模式布局写文案必然图文不符（典型：转换模式比新增模式少一个编号输入项，文案承诺填写后等到超时）。
- **控件类型与行内按钮文案会随状态切换**：同一字段可能是下拉也可能是单选组；同一行内按钮"首次建档"与"再次编辑"文案不同。须按状态分支分别探测，脚本用"或"匹配兼容两种形态，并对异步回读的状态加轮询等待（取到真实值再断言，不要只读一次）。
- **下拉选项可能被后端数据权限过滤**：探测必须用与录制出镜**同一账号**执行；演示数据的归属节点要落在该账号可见子树内，否则录制时展开是空的而探测时全量可见。
- **开录前做关键字段门槛校验**：任一关键事实缺失（字段清单为空、按钮不可点）→ 拒绝开录并提示先做起点复位。
- **每次正式录制前重探一遍**：探测与录制之间页面若变化，文案就会说谎。
- **选项文案一律以回读为准**：手写的"通过"实为"审核通过"、"根节点"实为"顶级"，点了不命中。

## 3. 成片与工具链级陷阱

| 现象 | 根因 | 处置 |
|---|---|---|
| 终端中文乱码 / 子进程中文输出成问号 | 控制台编码非 UTF-8 | 显式设置控制台输出编码为 UTF-8；数据库客户端另设其自身编码变量 |
| 成片比目标长 20% 以上 | 换人登录、弹框动画等实拍成本未计入规划 | 按每身份约 25s 重新规划，或与需求方确认取舍 |
| 弹框提交不关且无红字提示 | 后端返回 4xx 而前端不弹错误（典型：某字段有格式白名单，如仅允许字母数字） | 用探针直捕提交接口响应体定位；演示数据命名先对校验规则 |
| 音频体检"全员报尾部被切" | 拿 `silencedetect` 最后一次 `silence_start` 去比音频标称时长——本地 TTS 结尾普遍有 0.4~0.6s 低于阈值的尾音衰减 | 判完整性改用时长换算；对源音频单独跑一次 silencedetect 确认这段差值是引擎固有尾音 |
| 电平解析成 NA / 误判无声 | `volumedetect` 统计**只写在 stderr**，且字段名是 `mean_volume`/`max_volume`；`-inf` 转数字得 NaN | 用能拿到 stderr 的方式调用；判无声写 `!(max > -60)` 以覆盖 `-inf` 与 NA |
| 抽帧拼网格报"Cannot write more than one file with the same name" | 补位用的 `color` 源默认是无限帧流，与单帧图片混拼后输出多帧 | 给 `color` 加 `d=1`，输出侧加 `-frames:v 1` |
| 拼网格报"Value 1.000000 for parameter 'inputs' out of range [2 - …]" | `hstack` / `vstack` 的 `inputs` 下限是 **2**，单行表（不足两行）或单列网格直接非法 | 单行时直接 map 那一行的标签，单列时跳过 hstack；不要给滤镜写 `inputs=1` |
| 拼网格时高低分辨率源混拼报错或画面被裁 | `hstack` 要求各输入高度**完全一致**，`scale=W:-1` 按各自比例算出的高度不相等 | 先统一 `scale=W:H:force_original_aspect_ratio=decrease` + `pad` 补黑边 + `setsar=1` 再拼；目标高度取偶数 |
| 音频体检"统计全为 NA"但退出码看似正常 | `-af` 是**输出**选项，拼在 `-i` 之前会被 ffmpeg 当输入选项忽略，根本不跑滤镜 | 输入定位项（`-ss`/`-t`）放 `-i` 前，`-af` 放 `-i` 后；脚本要验证统计行真的解析到了数值 |
| 逐段体检报出一堆"开头静默 8~9s"、全部不合格 | 拿**流程时钟**的 timeline 去换算**已插引导卡的成片**，取样窗口落在静音卡片上 | 逐段门槛只对未插卡的全链主摄跑；成片只跑全片级门槛（见 verification.md §2） |
| 抽帧拼网格报"output unconnected / Error binding filtergraph" | 补位格子按"整表容量"补齐，留下未连接的 filter 输出 | 只按尾行缺口补齐：`(列数 − 帧数 % 列数) % 列数`；网格必须每行 hstack、行间 vstack，单用 concat 只会得到竖直长条 |
| 卡片中文渲染成方块或路径报错 | filter 里绝对路径的盘符冒号转义与命令行编码会破坏中文 | 文案写 UTF-8 无 BOM 文件，用 `textfile=` 裸文件名并把 ffmpeg 工作目录切到该目录 |
| 还原脚本报成功但数据没变 | 脚本包在 `BEGIN;…COMMIT;` 里且未开"出错即停"，中途报错仍返回退出码 0 → 整体回滚 | 必须带 `ON_ERROR_STOP=1` 一类参数 |
| 等价校验出现"行数翻倍"等无法解释的残差 | 基线还原按命名前缀删，漏掉批量保存写入的无前缀行 | 改用审计流水反推（见 data-reproducibility.md §2.4） |
| 切片后音画错位、语音落到别的段 | 切片换算漏了音频偏移量，或误用了上一轮 timeline | 见 SKILL.md「录制策略」；切完必须逐段验音轨 |
| 调用工具 `ENOENT` / 不在 `PATH` | 工具链只在特定 shell 的 PATH 里可见 | 整条链路从该 shell 的入口脚本启动，并在自检提示里写明 |
| 体检「全部通过」但数据是假的：抽帧整体偏移、段尾留白算成 0.00s、覆盖率虚高 | timeline 字段改名（`start_ms`、`audioMs`、`videoMs` 等）后脚本里 `a ?? b ?? 0` 静默退化成 0，取数错到别的段落却仍返回退出码 0 | 字段取值统一交给 `scripts/timeline.mjs` 解析：必填解析不到直接报错并列出该段实际键名，可选回落必须在输出里打 "⚠ 取值降级"（见 verification.md §2） |
| 观众每隔十几秒撞见一张 4 秒静止卡，片长虚增 20% | 录制计划按「一次菜单导航 = 一个片段」切，中间卡数等于导航数 | 卡片只插开头总览列出的大阶段边界，阶段内改用旁白过渡句衔接；密度门槛与人工确认闸门见 SKILL.md §0.5 |
| 插卡成片体检报 0 问题，却把片头/片尾/一个 5s 卡片外空洞全归成"卡片候选" | 卡片静音豁免按「静音长度 ≤ 卡长+2×门槛」**粗筛**，只看长度不看位置，任何短于该上限的静音都被吞 | 改成**位置感知**：由拼接脚本按各件时长累加落盘卡片坐标 `cards:[{id,startMs,endMs}]`（成片时钟），体检用 `--cards-at` 传入，静音段须与某卡区间重叠才豁免；卡片外静音按段间容差（含 TTS 尾音余量）判，超则报错（见 verification.md §2） |

## 4. 归因方法

失败时先分诊再动手，两类问题混在一起调试会导致无法归因：

- **管线级**（工具链、编码、字体、混流参数、路径）→ 用冒烟片隔离，与业务无关。
- **业务级**（选择器、断言、数据、文案）→ 用最小复现探针取证：转储真实 DOM 结构、捕获接口响应体，据证修改。

> 凭猜测改代码的代价是又一轮全链实时重录。
